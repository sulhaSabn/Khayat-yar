# خیاط‌یار PRO

سیستم حرفه‌ای مدیریت کارگاه خیاطی با ثبت‌نام اجباری، جداسازی کامل اطلاعات هر کاربر، مشتری و اندازه‌های مرد/زن، سفارش، پرداخت، هزینه، کارمندان و موجودی.

## امکانات نسخه PRO

- ثبت‌نام و ورود اجباری؛ بدون حساب هیچ اطلاعاتی نمایش داده نمی‌شود.
- جداسازی کامل اطلاعات هر کاربر با `ownerId` در همه رکوردها.
- رمز عبور با `bcrypt` هش می‌شود و احراز هویت با JWT انجام می‌شود.
- مشتری و سفارش در یک فرم قابل ثبت است.
- اندازه‌های **مرد** و **زن** کاملاً جدا هستند و با هم قاطی نمی‌شوند.
- فرم اندازه مرد: قد پیراهن، شانه، آستین، بغل، بر دامن، قد شلوار، بر تنبان، پاچه، یخن، بر یخن، کف، دهن آستین.
- فرم اندازه زن: قد پیراهن، شانه، آستین، بغل، کمر، بالاتنه، سورین، قد کرتی، قد واسکت، قد دامن، قد شلوار، بر دامن، پاچه، بر یخن، دهن آستین.
- واحد سانتی‌متر و اینچ.
- سفارش با قیمت، تخفیف، پرداخت اولیه، پرداخت‌های بعدی، تاریخ تحویل و وضعیت.
- وضعیت سفارش: ثبت‌شده، برش، دوخت، پرو، آماده، تحویل‌شده، لغو‌شده.
- هزینه روزانه: تاریخ، نوع هزینه، فرد انجام‌دهنده، مبلغ و شرح.
- کارمندان: نام، تماس، وظیفه/تخصص، حقوق ماهانه، تاریخ شروع، وضعیت و یادداشت.
- حقوق کارمند: پرداخت‌شده و باقی‌مانده حقوق **ماه جاری**؛ هر پرداخت حقوق به‌صورت خودکار به هزینه‌های حقوق نیز اضافه می‌شود.
- موجودی کارگاه: نام کالا، دسته‌بندی، مقدار، واحد، حداقل موجودی، قیمت واحد و ارزش کل.
- ورود کالا و مصرف/خروج کالا با تاریخ و شرح.
- هشدار کمبود موجودی.
- داشبورد حرفه‌ای با آمار مشتری، سفارش، دریافتی، هزینه، سود تقریبی، کارمند، حقوق و موجودی.
- گزارش مالی و وضعیت سفارش‌ها.
- طراحی RTL و مناسب موبایل.

## نصب

```bash
npm install
npm start
```

## متغیرهای محیطی

```env
PORT=3000
MONGODB_URI=mongodb+srv://USERNAME:PASSWORD@cluster.mongodb.net/khayyat_yar?retryWrites=true&w=majority
JWT_SECRET=یک_رشته_طولانی_و_محرمانه
```

## Render

Build Command:
```text
npm install
```

Start Command:
```text
npm start
```

Environment Variables:
- `MONGODB_URI`
- `JWT_SECRET`

`PORT` را Render خودش تنظیم می‌کند.

## نکته امنیتی

قبل از استفاده واقعی، مقدار `JWT_SECRET` را قوی و محرمانه قرار دهید و اطلاعات MongoDB را عمومی نکنید. هر API مربوط به مشتری، سفارش، هزینه، کارمند و موجودی نیاز به توکن معتبر دارد و رکوردها فقط با `ownerId` همان حساب خوانده یا تغییر داده می‌شوند.
